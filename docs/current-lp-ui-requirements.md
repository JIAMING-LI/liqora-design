# Liqora V1 UI 需求

> 版本：0.21 · 已关联准备兑换交易展示为 Swap<br>
> 日期：2026-09-11<br>
> 业务基线：[PRD v1.17](https://github.com/JIAMING-LI/liqora-docs/blob/main/prd/current-lp-performance-prd.md)<br>
> [交互原型 v0.21](../mockup/index.html)保持全英文，使用构造数据；已同步关联后的私有 Swap 活动及其生命周期。

## 1. 范围与设计目标

用户需要快速回答：当前有哪些 LP、盈亏多少、赚取的手续费去了哪里、近期手续费表现如何，以及扣准备兑换费用后还剩多少。

沿用两个页面：LP 总览和 LP 详情；费用关联为按需打开的流程。本期增加已全部撤出流动性的历史周期，与当前持仓复用详情项目。区间外、部分减仓仍属 Open；NFT 转移不算平仓、不重置周期，全退重建另起周期并保留旧周期。历史归属平仓时持有的钱包，之后 NFT 销毁或转出不删除历史。首批仍为 Robinhood Chain、标准 Uniswap V4、无 Hook、SPY/USDG。只读，不发起资产交易。

以用户提供的 [Efferd Dashboard-2](https://efferd.com/blocks/dashboard#dashboard-2) 和[参考截图](../mockup/designs/dashboard-2-reference.png)为当前视觉目标：白底、细线网格、少量图表色彩，字体沿用参考页默认 Geist。删除左侧 sidebar 及预留空白，内容在页面居中；保留顶部品牌／钱包入口，点击品牌返回总览，详情保留 Back to positions。首屏从 Open 统计开始，再显示图表与仓位列表；进入详情后展示单个 LP 的费用、资产、区间和活动。

详情采用用户新提供的[横向详情参考](../mockup/designs/detail-layout-reference.png)：上方身份和周期、横向四项指标、下方费用与资产区间双栏、底部活动。统一首页的 Geist、Reicon 和细线；费用关联使用原生 dialog 居中弹框。品牌使用用户提供的 `liqora-logo-v2.svg`。主设计尺寸 1440×1024，并检查 1100px 桌面宽度。不新增手机、平板、主题切换或独立分析页面。

不恢复数据核验、独立分析、来源管理、候选交易、私有名称、池子费率工具等模块。参考观察与指标取舍见 [Revert 页面观察](revert-reference-review.md)。

### 1.1 一期语言

所有用户可见内容均为英文，包括导航、指标、tooltip、表单、验证与签名说明、加载／空／错误／成功状态，以及原型的演示状态、示例标签和浏览器标题。本文保留中文业务说明，不能将这些说明直接作为中文 UI 文案。沿用两个页面，不加入语言切换或多语言框架。

数字使用英文千分位与小数点；金额和价格统一加 `$`，不重复写 USD；比例保留正负号。美元估值口径不变，代币符号 USDG 不删改。日期示例为 `Sep 10, 2026, 10:00 UTC+8`，表格可将时区放在表头。首页列表固定 `24h`，只在详情提供 `1h / 24h / 7d / 30d` 周期切换。

### 1.2 视觉规范

参考页的白底和极简线条为主体，用图表与真实品牌 Logo 提供少量色彩。

| 用途 | 颜色／规范 | 使用方式 |
|---|---|---|
| 主背景 | `#FFFFFF` | 全页与内容同一白色表面 |
| 次级底色 | `#F2F4F2` | 选中状态、表头和费用摘要 |
| 主文字 | `#1E2327` | 标题与指标；数字等宽对齐 |
| 次级文字 | `#5B646B` | 说明、单位与元数据 |
| 分隔线 | `#E2E6EA` | 1px 边框，卡片 12px 轻圆角，无厚阴影 |
| 正向／区间内 | `#287862` | 盈亏数值与明确状态文字 |
| 负向／异常 | `#B34E5B` | 负值与错误；不能只用颜色表达 |
| 图表系列 | `#8FA0A8`／`#C9D1C8` | 多系列烟灰蓝、苔绿；同时显示名称、数值和占比 |

字体使用 **Geist**（参考页 CSS 的默认字体），本地托管 WOFF2；不加入字体切换。主标题 28px、区块标题 17–20px、总览金额 24–26px、正文 12–14px；输入与焦点保持足够对比。四项指标使用独立轻圆角卡片，间隔 14px（窄桌面 10px）；图表与账单同用 12px 圆角。按钮与选项保留 4–6px 圆角。品牌标识主色为 #5CA1FF；界面图标用黑色 #1E2327（深色按钮图标保持白色），单系列曲线统一烟灰蓝 #8FA0A8，正文仍使用深色，盈亏正负保持绿／红语义色。

UI 图标统一使用 [Reicon](https://reicon.dev/) 的 Outline 样式，保持库原始路径，通常 17–21px；仅图标的按钮必须有英文可访问名称。代币 Logo 在列表使用 24px、详情使用 30px 双图标；列表币对名称和主数值约 13px，详情代币明细用两行 10–11px 次级文字和 15px 小图标，链与协议 Logo 在其名称旁使用 13–20px。来源优先官方素材或官方 token metadata，保持比例与原色，不用字母占位或自行绘制的图案冒充 Logo。素材来源见 [assets/README](../mockup/assets/README.md)。

## 2. 查询与权限

- 输入地址即可查看公开仓位，无需签名；也可连接钱包取得查询地址。地址格式错误紧邻字段提示。
- 总览为钱包维度，顶部不绑定单条链或单个协议；链和协议只在各仓位身份中展示。查询包含该钱包已接入的当前与历史 LP，状态仅筛选列表，顶部统计固定聚合 Open，不把未接入数据冒充已查询。美元估值固定，不提供基准切换。
- 查询钱包和连接钱包区分，缩写可复制全文。连接不等于签名验证，错误钱包不能保存私有记录。
- 显示真实数据截止时间及明确时区，正常每 60 秒刷新，可手动刷新；请求完成时间不能冒充数据时间。
- 未验证、验证失败或身份失效时，只显示公开 LP 盈亏；私有费用是否存在、数量和金额均不可泄露。
- 验证成功并恢复记录后，可切换 `PnL / Adjusted PnL`。列表、详情和合计统一口径；切回公开口径不删除记录。
- 换地址、断开或身份失效时立即隐藏旧钱包私有内容。恢复失败提示重试，不伪装成没有记录。

## 3. 当前与历史 LP 总览

### 3.0 状态 Tab

按最新[融合参考](../mockup/designs/integrated-table-reference.png)，将 Tab 与表格放入同一张卡片：顶部工具栏内左侧为四个 Tab，右侧保留固定 Fee APR · 24h，下一行直接接列标题。整块使用一个外边框与圆角，工具栏下用细线分隔，不保留独立页签区域与表格间空隙。Tab 缩为约 12px 字号、30px 按钮高度、6px／12px 内边距；保留浅灰绿底、白色选中项和键盘焦点。参考中的期间切换不引入首页，首页 APR 仍固定 24h。

按[用户截图](../mockup/designs/position-tabs-reference.png)在列表区域直接替换原 Current positions 标题，放置浅灰绿色分段页签。页签位于总览图表下方，与 Fee APR · 24h 说明同一行，不放在统计卡上方。顺序为 `Open position (N)`、`In Range (N)`、`Out of Range (N)`、`Closed position (N)`。选中项白底、轻阴影、深色文字；沿用 Geist 与现有间距，不复制截图中的固定数量。

- 默认 Open；In Range 与 Out of Range 仅筛选当前持仓，Closed 展示全部撤出流动性的历史周期。同 NFT 多周期分别计数。
- 切换只更新列表，四项总览统计、前日变化和两张图表始终显示全部 Open positions。详情返回保留选中的 Tab；图表中的仓位入口始终打开对应 Open 详情。
- 使用 tablist／tab／tabpanel 语义，选中项可用 Tab 键到达，左右方向键及 Home／End 切换，有清晰键盘焦点。
- 列表保留现有列；Closed 的 Cycle age 改为 Cycle duration，时长停在平仓时点。状态显示 Closed，区间价格标记为 Price at close，不按今日价格继续显示区间内外。
- 无当前仓位时 Open 为零，仍可选择 Closed；所选集合为空显示 No matching positions，读取失败单独提示，不能冒充零条。
- Closed 列表与详情的 Position value 通常为 0，未领费用结清时 Uncollected 为 0；取回本金、费用与历史 PnL 仍保留。总览不切换为 Closed 合计或历史图表，没有 Open 时总览才为空。

### 3.1 顶部指标栏

在同一条紧凑摘要中并列：

| 指标 | 展示规则 |
|---|---|
| 当前仓位价值 | 当前 LP 的流动性价值合计，明确“不含未领取手续费” |
| LP 盈亏／扣准备费用后盈亏 | 固定 USD 历史收支基准，含 LP Gas；可选准备费用单独扣除 |
| 手续费汇总 | 已领取（含复投）历史 USD＋当前未领取 USD；标“展示值，已计入盈亏，不再加一次” |
| 未领取手续费 | 当前同一截止区块的余额估值合计 |

首页顺序固定为 Position value → Uncollected fees → Total fees → PnL；保留 Total fees，不改成钱包整体 APR。每项都有 Reicon 图标；首页不展示 LP Gas 卡片，Gas 仍参与盈亏计算并在详情列出。卡片下方显示较 24h 前钱包快照的变化，增加用绿色上升箭头、减少用红色下降箭头；缺少可比快照显示不可用，前值为 0 时展示金额变化而不计算无穷百分比。变化包含钱包当前 LP 集合变化，不能称为投资回报率。PnL 百分比变化除以前值绝对值；调整口径的历史值也必须扣历史已关联费用。原型使用明确构造的前日快照。投入盈亏比保留在单 LP 详情，不显示钱包平均 APR。

### 3.2 总览图表

统计下方并列两张图，与顶部指标使用同一 Open 仓位集合和估值截止时间，四个列表 Tab 均不改变它们：

- **Position allocation**：按当前仓位价值绘制柱图，零起点；每个 LP 用币对名称展示，并附美元价值与占比；同币对多仓位使用价格区间区分，NFT ID 不作为图表标签。图下的仓位入口可点击或用键盘进入详情。
- **Fee breakdown**：按各 LP 的当前未领取手续费绘制环图，不含已领取（含复投）。中间显示未领取合计，图例显示币对、区间、金额及该 LP 占比。各 LP 的 Collected 与 Uncollected 在详情展示。
- 不依赖悬停才能读数；图形旁的文本包含等价数据。颜色只作辅助，不加没有数据依据的涨跌百分比、日期轴或随机趋势线。
- 费用口径与 APR 时间窗口切换不改变这两个当前快照图。空集合显示明确空态，分母为零显示 0.0%，缺历史投入价格时仍可展示有依据的当前仓位／费用分布。

### 3.3 当前仓位列表

列顺序：仓位／币对（不展示 NFT 编号）、当前价值、盈亏、手续费 APR、未领取、区间、本次周期时长、详情入口。

- 表头 APR 固定 24h，不放窗口切换控件；周期不足显示“—”及 `Under 24h old` 等原因。
- 详情允许切换周期，仅改变详情期间指标；返回首页后列表仍按 24h 展示，不受详情所选周期影响。
- 区间显式显示 `Pool $…`、Min、Max，位置条以实际价格计算带宽和当前竖线的位置。区间带与价格指针均用低饱和蓝，区间外保留红色 `Out of range` 状态文字。原始 USDG/SPY 上下限乘 USDG 的美元价格后才显示 `$`，不能直接替换单位；原型 480–530 USDG/SPY 对应 $475.20–$524.70。
- Value、Uncollected fees、PnL 三列仅展示主数值，不加币种明细、盈亏比或其他次级数据。币种明细与盈亏比在详情展示。
- 每行币对旁显示两个代币 Logo，次级信息显示链 Logo、协议 Logo 与名称；整行可点击，保留有明确名称的详情按钮作为键盘入口。
- 本次周期从实际建仓开始，非钱包接收 NFT 时长；身份和时间作为次级文本，不再占用大卡片。
- 总览不展开完整本金流水、收益归因或池子行情。

确认所选列表集合为空时显示列表空状态；总览仅在 Open 为空时为 0 或空图。读取失败保留旧快照及时间；Open 部分仓位缺历史投入价格时总览盈亏不可计算，即使列表正在查看 Closed 也不改口径，历史详情仍可按自己的完整数据展示。全退从 Open 移入 Closed；单纯转出从 Open 移除，不伪造平仓，不把集合变化描述为新增亏损。

### 3.4 多交易对 Demo

Open 与 Closed 均使用 SPY/USDG、ETH/USDG、NVDA/USDG、CRCL/USDG 演示。币对名称、双币 Logo、图例、详情表头、Price per {token}、价格范围及活动数量使用仓位对应代币，列表 Range 列不再写死 SPY。固定演示价格分别为 $500、$2,500、$180、$120，USDG 为 $0.99；不作为实时行情或真实接入承诺。准备费用使用各币种独立的示例交易，同源费用额度在同币种的当前／历史周期之间共享，不跨币种混用。

## 4. LP 详情

历史仓位复用下面全部展示项和同一详情组件，包括费用关联流程，无需另一版历史详情。顶部补充 Closed、Opened 与 Closed 时间。Position value 为 0，创建／累计投入、取回本金、费用和盈亏沿用原周期账务；全退后尚未领取的费用继续显示，后续领取与 Gas 归属原周期，不带入重新建仓的周期。APR、窗口平均本金／新增费用／日均、区间价格和趋势截止平仓；趋势标 24h ending at close，末点标 Closed，View data 使用历史绝对日期。历史数据缺失不借用当前或其他周期，费用结清后的金额不随当前币价重估。

历史私有费用按“所属钱包＋仓位＋周期”隔离，允许该钱包验证后继续管理；同 NFT 的当前和历史周期不能共享或覆盖关联。现有扣准备费用后的盈亏切换同样适用历史集合。

### 4.1 层级

1. 顶部左侧返回、币对与区间状态，右侧 Period；下方一行网络／协议、NFT ID、poolId、建仓时间，美元金额用 `$`。
2. 横向四项摘要依次为 Position value、Total fees、Fee APR、PnL。Total fees 金额为本周期 Collected + Uncollected，变化与前日 Total fees 快照比较；缺少前日汇总时不以未领取金额代替。首页和列表继续显示原有未领取项目。金额缩小至 25px（窄桌面 23px），四项均有图标及较 24h 前变化，结构与首页一致；盈亏比放资产区。APR 比较相同窗口在前日快照的值，前值为零时使用百分点差；LP 创建不足 24h 或快照缺失时变化不可用。
3. 指标下方并排展示 Position value trend 与 Fee APR trend，规则见 §4.5。
4. 左栏 Fees & costs：手续费各去向、期间手续费／平均本金／日均、LP Gas、准备费用及关联按钮；右栏 Assets & range：区间、当前价值与代币数量、创建投入、累计投入、取回本金、盈亏比与公式。
5. 下方列本次周期链上活动，按[用户截图](../mockup/designs/activity-reference.png)采用 Txn Hash、Type、Balance、Total Value、Tx fee 五列。哈希色签位于每行左上角，时间与链 Logo 在下方；操作带图标及合约地址；Balance 直接展示双币小 Logo、带方向数量及历史美元价值；总价值与原生 Gas 数量／历史美元 Gas 独立成列。减仓并领取须拆为同哈希的 Withdraw／Collect 两行，分别展示本金与手续费，复投须标示移入 LP 本金；只读原型哈希与合约按钮打开示例信息。可用展开的短公式说明，不设独立分析页。

视觉稿可以改变分组位置，不能改变字段口径、窗口范围或访问权限。

### 4.2 手续费与期间指标

所有涉及双币的账单行都展示两币符号、小 Logo 和各自美元价值，包括 Total fees、Collected、Uncollected、期间费用、平均本金及资产项；有对应数量时一并显示，零值币种仍保留。累计项保留各自历史估值，不能将币种汇总数量统一乘当前价代替。

| 内容 | 展示 |
|---|---|
| 手续费汇总（展示值） | 已领取（含复投）与未领取合计；不可直接用于 APR 或再次加回盈亏 |
| 已领取 | 包含领取到钱包和直接复投，按结算时数量与 USD 累计；提示 Includes fees collected and reinvested |
| 未领取 | 当前代币数量及同一截止区块的 USD |
| 窗口新增手续费 | 所选完整窗口内实际赚取的手续费，按产生时段 USD 估值，不是本期领取额 |
| 平均本金 | 同窗口时间加权仓位本金，含复投后本金及区间外时间，不含单独未领取 |
| 手续费 APR | 新增÷平均本金×365÷窗口天数，Gas 与准备费用不扣入 |
| 窗口日均手续费 | 同窗口新增÷窗口天数；1h 必须写“过去 1h 折算日均”，非当日已赚或预测 |

1h／24h／7d／30d 对 Open 从当前数据截止时间向前滚动，对 Closed 从平仓时点向前计算，1h 为完整 60 分钟。本次周期只有 8h 时，1h 可用而 24h／7d／30d 不足；只有 30 分钟时 1h 也不可用。不偷偷切换窗口或补用其他周期。

窗口不足或手续费缺价时，影响相应指标；仅缺平均本金时，已有依据的新增和日均仍可显示，APR 不可用。手续费汇总某项缺失不等于所有指标都缺失；已知明细照常保留。

LP gas 的美元合计下补原生 Gas 币种、数量及小 Logo；原型为 ETH，首个 LP 为 0.002000 ETH／$5，第二个为 0.001600 ETH／$4。原生数量应来自实际支付记录，美元金额按各笔历史估值累加，不能拿当前价反推真实 Gas 数量。

### 4.3 本金、区间与盈亏

详情区间采用浅蓝灰底价格尺：12px 细区间带、两端边界线、圆点当前价指针与浅色价格标签。上方明确 Current price，Min／Max 直接对齐对应边界。范围带和指针均用低饱和蓝，区间外保留红色状态文字；位置仍按实际价格比例计算。

分别展示创建时价值、当前仓位代币组成；累计投入、已取回本金作为固定行显示，零取回用弱化颜色。创建／追加（含复投）按投入时估值，Total deposits 提示 Includes reinvested fees；取回按发生时，当前仓位按当前区块。USDG 不默认等于 USD；缺价保留原币数量。

```text
LP 盈亏 = 当前仓位价值 + 未领取 + 已领取
          + 已取回本金 − 累计投入 − LP 操作 Gas
扣准备费用后盈亏 = LP 盈亏 − 已关联且尚未扣除的准备费用
投入盈亏比 = 当前选择口径的盈亏 ÷ 累计投入 × 100%
```

比值非年化，不叫总 APR 或通用 ROI；减仓不缩小分母，领取再投入及直接复投增加分母。分母为零或缺失时不可计算。NFT 转移不重置历史，不把结果称为当前持有人买卖 NFT 的个人收益率。

当前价、上下限与区间状态只读。直接复投按同一金额同时增加已领取与累计投入，不单设指标；手续费汇总不再加到此公式中。活动按同一哈希展示 Collect 与 Deposit，注明手续费再投入，Gas 只计一次。部分操作费用未计入时紧邻盈亏说明范围，不能声称全部成本已扣。

### 4.4 活动

每条活动的第一列左上角按[手绘参考](../mockup/designs/txn-tag-placement.jpg)贴行顶边显示 `Txn 0x1234…abcd` 小标签，标签自身带背景色；时间与链 Logo 位于下方，不重复显示另一份 hash。点击／键盘激活沿用交易详情入口，完整 hash 可通过标签 title 和示例详情读取。颜色标识交易，不标识 Deposit／Collect／Withdraw／Swap 类型；同一 transaction 的多条活动保持相同颜色，包括 Withdraw＋Collect 与 Collect＋Deposit。

按[中性色卡](../mockup/designs/txn-palette-neutral.jpg)与[蓝黄色卡](../mockup/designs/txn-palette-blue.jpg)合并近似黄、米色，保留 6 种标签底色：深蓝 `#3674B5`、金黄 `#E9BE5F`、灰绿 `#595C56`、米白 `#F5F0CD`、浅蓝 `#578FCA`、炭黑 `#282823`。深底白字、浅底深字，普通文字对比度至少 4.5:1。原型按完整示例交易集合排序分配六色，同一 hash 跨详情保持一致；超过六笔交易循环用色，具体身份始终以 hash 为准，不能只靠颜色判断。整行保持白底。

需求定义 **4 种 Type**：Deposit、Collect、Withdraw、Swap。前三种来自 LP 操作；Swap 仅展示已关联的准备兑换交易。v0.21 原型已实现四种，Swap 需要保存关联并保持钱包验证状态才显示。

| Type | 定义 | 金额与记账 |
|---|---|---|
| `Deposit` | 首次建仓、追加流动性，或把已领取手续费再次投入 LP | 从 LP 外流入仓位，Balance／Total Value 为负；增加累计投入。首次建仓另记创建投入 |
| `Collect` | 领取本周期赚取的手续费，包括随后直接复投的领取步骤 | Balance／Total Value 为正；增加 Collected，减少对应未领取；领取本身不重复增加 Total fees |
| `Withdraw` | 取回流动性本金，包含部分减仓和完全平仓，不含领取手续费 | Balance／Total Value 为正，仅增加 Principal withdrawn；只有流动性全部撤出才结束周期 |
| `Swap` | 已成功关联到当前 LP 周期的准备兑换交易，标记 `Linked preparation`；只有该记录所属钱包验证后可见 | 展示原兑换支付／所得，并区分原交易费用与当前 LP 分摊费用；兑换金额不计入 LP 投入、取回或手续费收入，仅已分配且尚未扣除的成本影响 Adjusted PnL |

Type 表示业务操作，不等于交易哈希，也不等于 Open／Closed 仓位状态。一笔复投交易按同一哈希显示 Collect 与 Deposit 两行，不新增 Reinvest 类型，Gas 只归属一次。同一笔交易取回本金并领取手续费时，拆成 Withdraw 与 Collect 两行，共享 transaction hash 和时间，各自只展示本金／手续费对应的代币数量与金额；Gas 归在 Withdraw 行，Collect 行注明已在同笔 Withdraw 计入。纯减仓仅显示 Withdraw，纯领取仅显示 Collect，不保留合并类型。准备代币的 Swap 在关联保存成功后纳入 Recent activity；NFT 转移、失败操作目前无独立活动示例，不能据此声称已实现完整链上类型覆盖。

按时间倒序，采用 §4.1 的五列表格；左上角哈希色签／下方时间分层，完整时间及时区可查看。双币数量直接显示，不需要展开。减仓的本金和手续费分开；直接复投注明只改变去向。失败但实际支付且可归属的 LP Gas 也计入，同笔交易 Gas 只扣一次。

Swap 使用源交易 hash、链与原交易发生时间，沿用同交易同色标签；可能早于 LP 建仓，应按原时间排序并保留，不使用关联时间。活动范围包含本周期 LP 操作与已关联准备交易，不能将全部记录标注为建仓后的链上操作。

关联未保存、解析成功但未保存、保存失败均不新增活动。修改更新对应 Swap 行，重复保存不增加重复行；撤销关联移除该行，公开查看／断开验证隐藏私有 Swap，重新验证后恢复仍存在的关联。已有 LP 操作行不因解除关联被删除，同一 transaction 的公开操作仍可见。

产品中哈希打开对应链区块浏览器；构造原型标“示例哈希”，不伪装成真实记录。无需额外账本搜索、交易证据面板或收益归因系统。

## 5. 可选关联准备兑换费用

入口统一 `Link preparation costs`；验证当前查询钱包的控制权后操作。签名不发送链上交易，取消／失败仍可继续公开查看。

弹框宽 920px，居中、12px 圆角；保留原生焦点约束、Esc 关闭及关闭后焦点返回。顶部显示币对、NFT／建仓周期和 Private 标识，两个步骤为 Find transaction → Allocate costs。第一步集中输入 hash；解析后左栏展示原交易的支付／所得和费用，右栏填写用于该 LP 的数量并实时预览分配比例、费用与 Adjusted PnL，底部统一取消／保存。超高内容在框内滚动，1100px 桌面不能横向溢出。

流程：输入 hash → 解析支付／收到 token、实际数量、兑换费及 Gas → 指定用于本 LP 的所得数量 → 预览比例、分摊及调整后盈亏 → 保存。

只读展示原交易、网络、费用发生时间及原始费用，不做钱包候选扫描；无法明确解析时提示不支持，不手填费用。数量大于 0、不超原币精度和可分配余额，修改时包含旧记录占用数量，其他 LP 分配仍占额度。

总兑换费已含 LP fee／protocol fee 时只扣总额；Gas 已算入 LP 操作费用时标“本次不再扣除”。关联只改准备成本及相应盈亏／投入盈亏比，不改投入、手续费汇总和 APR。重复保存替换旧结果；撤销释放额度，不用数量 0 暗中删除。

产品记录保存至数据库，正确钱包重新验证后恢复；保存／修改／撤销成功同步列表、详情金额与 Recent activity 中对应 Swap 行，展示规则见 §4.4。无效 hash、错误钱包、解析失败、缺费用价格、超额或保存失败就地报错；原记录不变，保存失败保留草稿。NFT 转移不共享前持有人私有费用。

## 6. 状态、可访问性与验收

加载和后台刷新不闪烁、不覆盖输入，失败不更新时间；未知不填 0。金额两位小数、千分位、单位和正负号；小额非零用小于 0.01 表达。

普通文字对比度至少 4.5:1；状态同时有文字。按钮及输入支持键盘、可见焦点；标签持续可见、错误就地；对话框关闭后回到触发位置，Esc 可取消。支持浏览器缩放和减少动态效果偏好。

不引入总 APR、HOLD／ETH 基准、PnL 曲线、24h 盈亏变化、无常损失、奖励、池子行情图表或交易动作。总览快照图见 §3.2，详情新增仓位余额与 APR 趋势见 §4.5；这不扩展为 PnL 曲线或独立分析页。
